# Jyzrox Web Clipper

Load this directory as an unpacked Manifest V3 extension in Chrome or Edge. Open the extension options, enter the Jyzrox origin, and sign in to that Jyzrox instance in the same browser.

- **Send image to Jyzrox** fetches the selected image in the browser with its existing site cookies, then uploads the bytes to a private `webclip` gallery.
- **Send to Jyzrox** sends the current page or selected link to the normal Jyzrox download queue.

The extension requests broad host access because authenticated image URLs can come from any configured gallery source. Chrome displays this permission during installation.
